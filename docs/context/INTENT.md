# INTENT

## 判断原則

- 個人利用のローカル確認体験を最初に成立させる。
- 公開化、独自ドメイン、認証、定期実行は、データ構造と画面体験が確認できた後に判断する。
- 原文記事の権利と取得先サイトの負荷を優先し、全文保存や全文転載をしない。
- 要約、タグ、重要度、示唆は、原文を読むための優先順位付けと理解補助として扱う。
- 収集対象サイトは、RSS があるサイトまたは公開ブログ一覧ページから始める。
- 最初から対象サイトを広げすぎず、取得しやすく確認価値が高いサイトに絞る。
- 公開 LP で記事をどう表示するかを決めるために記事内容の確認が必要な項目は、公開 LP 側ではなく `rm-trend-radar` 側の確認作業で確定する。公開 LP 側は、確認済み export の値を使って表示を組み立てることを優先する。
