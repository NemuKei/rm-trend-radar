# spec_000_overview

## Purpose

`rm-trend-radar` は、ホテル・レベニューマネジメント領域の海外公開記事を収集し、日本語で確認するための個人用 Web アプリである。

この仕様は、リポジトリ全体の目的、MVP の範囲、保存するデータ、扱わないこと、今後追加する仕様文書の責務を定義する。

## Scope

### In scope

- 公開 RSS または公開ブログ一覧ページから取得できる記事メタデータを扱う。
- 原文 URL、取得元、公開日、英語タイトル、日本語タイトル、日本語要約、タグ、重要度、レベニューマネジメント担当者向けの示唆、手動メモを保存する。
- Streamlit 画面で、新着記事、重要記事、タグ別記事を確認する。
- SQLite をローカルデータベースとして使う。

### Out of scope

- 記事本文の全文保存
- 記事本文の全文転載
- ログインが必要なページの取得
- 原文記事の代替公開
- 有料記事、会員限定記事、認証が必要な情報の取得
- Cloudflare、独自ドメイン、認証付き公開アプリへの展開
- 定期実行基盤の本番運用

## Inputs

- 公開 RSS または公開ブログ一覧ページ
- 記事の原文 URL
- 記事の公開日
- 記事タイトル
- 手動または将来の自動処理で作成する日本語要約、タグ、重要度、示唆、メモ

## Outputs

- Streamlit の記事一覧画面
- 重要度で絞り込んだ記事一覧
- タグで絞り込んだ記事一覧
- SQLite に保存された確認用メタデータ

## Data Policy

- 原文記事の本文全文は保存しない。
- 原文記事の代替となる長文転載は作成しない。
- 日本語要約は、原文確認を補助する短い説明として扱う。
- 出典サイト名と原文 URL を必ず保持する。

## Initial Acceptance Criteria

- Python 仮想環境を作成できる。
- `requirements.txt` の依存関係をインストールできる。
- SQLite データベースを初期化できる。
- Streamlit アプリを起動できる。
- サンプル記事が画面に表示される。
- 記事本文全文ではなく、原文リンクと確認用メタデータだけが表示される。
